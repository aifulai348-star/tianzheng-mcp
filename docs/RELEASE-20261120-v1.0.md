# MCP v1.0 封版说明（2026-11-20）

**状态：v1.0.0 封版（2026-11-20，git tag `v1.0.0`）。** 本地单实例 AutoCAD 2024 + T20 天正 V9 上，
墙 / 柱 / 门 / 窗 / 板 / 文字 / 多段线已可被 Agent 通过 MCP 安全调用；楼梯、坡屋顶仍是历史证据或未验证项。
下面每一条都指向可复查的证据文件。封版的条件是「已验证的写清楚、没验证的也写清楚」，不是「全都行」。

## 1. 交付了什么

- **9 个 MCP 工具**：`system_diagnose` / `list_capabilities` / `queue_submit` / `queue_status` / `queue_cancel` /
  `queue_acknowledge` / `worker_start` / `worker_stop` / `worker_status`。
- **15 条 capability**：见 `list_capabilities`；状态分级 `verified_live` / `unverified` / `historical_evidence`。
- **执行模型**：提交（`queue_submit`）与执行（worker）分离；任务落 sqlite，状态只有
  `queued / running / succeeded / failed / cancelled / unknown_outcome` 六种。
- **失败安全**：参数错在提交期拒绝；环境错落 `failed`；结果不确定落 `unknown_outcome` 并冻结队列，
  必须人工 `queue_acknowledge` 才能继续，且**永不自动重放**。
- **副作用留档**：`queue_acknowledge` 的 `side_effects` 是必填的——`unknown_outcome` 不等于没画，
  人要写清图上实际看到了什么（例：`"after the timeout <dwg> shows columns=1 walls=0 openings=0 cmdactive=0"`）。
  这句话进 job 的 `error`，另存 `<state>/acks/<job_id>.json` 回执，`queue_status` 会带回。

## 3. 已知限制（必须写进调用方的预期）

1. **门窗类型**：只验证了 `普通门` 与 `普通窗`；防火门/卷帘/人防门等其它类型、以及窗的 `防火窗` 与图库图标未验证。
2. **楼梯 / 坡屋顶**：`stair.create`、`stair.rect_create`、`roof.create` 仍是历史证据（`unverified`）。
3. **轴线不是对象**：本版天正轴线是 `DOTE` 层普通 `LINE`，验收要数线；轴号与标注是 `TDbAxisLabelSet` / `TDbDimension2`。
4. **COM 只连第一个 AutoCAD 实例**：必须单实例，或设 `TZ_CAD_PID` 指定；多实例时 worker 主动拒绝启动。
5. **不确定即停**：超时、模态弹窗、worker 被杀一律 `unknown_outcome`；此时图里**可能已经画上了**，所以不重放。
   人工确认时必须写 `side_effects`（图上实际看到了什么），这句会留档。
   边界：生产队列里那条 2026-11-17 的 `144ad30f` 早于本契约，按用户要求**保持未决、不清账**，
   它没有回执文件——新契约只约束从 v1.0.0 起的确认动作。
6. **前台要求**：天正命令只认带移动的真实鼠标点击；CAD 必须在前台（后台作业托管启动，勿用普通 shell 前台拉起）。
7. **多图纸**：已修 `input_bridge.activate_view` 选错视图的问题（2026-11-20），多图同时打开时按「焦点所在文档」选视图。

## 4. 上手（五分钟）

```powershell
# 1. 起 CAD（后台作业托管，避免 job object 连带杀掉）
Start-Process 'D:/天正/TGStart.exe'

# 2. 看一眼环境
cd <repo>
D:/python/python.exe -X utf8 bootstrap.py doctor
D:/python/python.exe -X utf8 bootstrap.py capabilities

# 3. 单实例时可直接跑；多实例必须钉住
$env:TZ_CAD_PID = '<autocad pid>'
$env:TZ_STATE   = '<repo>/_tmp/e2e2/state'   # 生产别指向 .state

# 4. 提交 + 执行 + 读结果
D:/python/python.exe -X utf8 bootstrap.py submit recipe.json
D:/python/python.exe -X utf8 bootstrap.py worker once
D:/python/python.exe -X utf8 bootstrap.py status <job_id>
```

工具面的完整契约（入参、返回、错误串、状态机）见 `docs/MCP-TOOL-SPEC.md`。
